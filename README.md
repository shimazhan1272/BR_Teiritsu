# ボートレース定率法

1レースに使う金額を「その時点の資金の○%」に固定して管理する Web アプリです。

## 使い方

1. 軍資金と割合(%)を入力して開始します。
2. 日付、レース場、レースを入力します。
3. 結果に応じて「的中」または「不的中」を押します。的中のときは払戻金額を入力します。
4. 履歴の「CSVで出力」から結果をダウンロードできます。

賭け金は「現在の資金 × 割合」を100円単位で切り捨てた金額です。100円未満になる場合は100円にします。
資金が100円未満になると「軍資金がなくなりました。」と表示し、記録できなくなります。

データは使用しているブラウザの localStorage にのみ保存され、外部には送信されません。
